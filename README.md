# Портфолио QA-инженера

Привет! Я начинающий QA-инженер, специализируюсь на **функциональном тестировании** веб-приложений.  
В этом репозитории собраны мои практические работы по тестированию поисковых строк на реальных сайтах.

---

## 🛠 Навыки

- **Виды тестирования:** функциональное, UI, usability, smoke.
- **Техники тест-дизайна:** классы эквивалентности, граничные значения, попарное тестирование.
- **Инструменты:** Excel, Google Sheets, Lightshot, DevTools, Yandex Browser, GitHub.
- **Документация:** Test Cases, Test Run, Bug Reports, чек-листы.
- **Домен:** e-commerce (электроника, обувь, книги, мебель, автозапчасти, семена, отели, оптика, спорт).

---

В каждом разделе — Excel-файл с тремя листами: **Test Cases**, **Test Run**, **Bug Reports**.

---

## 🧪 Что я тестировал

Во всех проектах проверялась **поисковая строка** по 4 ключевым сценариям:

1. Поиск по полному названию товара/статьи.
2. Поиск по частичному совпадению (3–5 букв).
3. Обработка опечаток и ошибок в словах.
4. Реакция на несуществующие слова и пустой запрос.

**Дополнительно:** проверка поиска по **синонимам** — когда одно и то же понятие называется по-разному.


---


В юзабилити шапки сайта проверялось:

1. Правильность написания
2. Переход на нужную страницу
3. Корректность страницы после перехода

## 🐛 Примеры найденных багов

### BR-CRITICAL: XSS-уязвимость
**Сайт:** centerfish.ru, minimum-price.ru, enter.online  
**Суть:** При вводе `<script>alert(1)</script>` в поисковую строку скрипт **выполняется** на странице.  
**Риск:** Кража cookies, сессий, персональных данных.  
**Рекомендация:** Санитизация ввода, экранирование `<`, `>`, `"`, `'`, CSP.

### BR-MAJOR: Нерелевантная выдача
**Сайт:** kazan.technopark.ru, enter.online, autozest.ru  
**Суть:** Поиск по частичному запросу выдаёт товары из других категорий.  
**Пример:** «Генер» → 88 холодильников вместо генераторов; «супертелевизор3000» → все телевизоры.  
**Рекомендация:** Ранжирование по релевантности, AND-логика для составных запросов.

### BR-MAJOR: Поиск не распознаёт раскладку
**Сайт:** autozest.ru, agrosemfond.ru, ruskniga.es, sdelaem.agency  
**Суть:** Запрос «cnfhnth» (стартер в латинице) → 0 результатов.  
**Рекомендация:** Транслитерация, определение раскладки, подсказки.

### BR-MINOR: Нет обратной связи
**Сайт:** sdelaem.agency, sports.kz  
**Суть:** Пустой запрос или пробелы → пустая страница без сообщения.  
**Рекомендация:** Валидация на пустой запрос, сообщение «Введите поисковый запрос».

## 🎯 Ключевые выводы

По результатам тестирования **13 сайтов** выявлены **системные проблемы** поисковых строк:

1. **XSS-уязвимости** — на 3 сайтах из 13.
2. **Нерелевантная выдача** — на 5 сайтах.
3. **Не распознают раскладку** — на 4 сайтах.
4. **Не обрабатывают опечатки** — на 5 сайтах.
5. **Нет валидации пустого запроса** — на 4 сайтах.
6. **Не распознают синонимы** — на 4 сайтах (на 9 — работают).

**Хорошо работают:** базовый поиск, поиск по артикулу, регистронезависимость, автодополнение.
